# Fusion Model Architecture Diagram

This directory contains two presentation variants of the dual-view enhancement and
fusion architecture:

- `simplified.html` preserves the original wide, strip-shaped overview for web and slide
  use.
- `paper.html` is the high-contrast `1120 × 792` A4-landscape source intended for the
  thesis. It rearranges the same seven components without removing or adding model
  behavior, and uses 16 px primary labels plus 12 px supporting labels.

The thesis raster is `Thesis/figs/fusion-model-architecture.png`. Export `paper.html` at
3× (`3360 × 2376`) when refreshing that file.
